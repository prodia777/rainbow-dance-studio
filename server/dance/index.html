Rainbow Dance Studio

音楽に合わせて Rainbow Stick が踊る振付アプリ（Android版）

Androidアプリをダウンロード

バージョン 0.1.0（試作版）

インストールのしかた

  1. 上のボタンでファイル（RainbowDanceStudio.apk）をダウンロードします。
  2. ダウンロードが終わったら、通知またはファイルアプリから開きます。
  3. 「この提供元のアプリを許可」の画面が出たら、許可してから戻ります。
  4. 「インストール」を押します。Google Play プロテクトの確認が出た場合は「インストール」を選びます。

使える曲

スマホに保存した MP3 などの音楽ファイルを選んで使います。曲はスマホの中だけで解析し、外部には送信しません。配信サービス（YouTube・Apple Music・Spotify など）の曲は使えません。

iPhone版は準備中です。

English: Tap the button to download the Android app (APK). Open the downloaded file, allow installation from this source when asked, then tap Install. Use music files saved on your phone; streaming services are not supported. iPhone version coming later.
